## 3. Defects found (confirmed by throwaway probe tests unless noted)

| # | Sev | Module | Defect |
|---|---|---|---|
| D1 | High | identity | `assertPermission` ignores `Role.tenantId`: a role belonging to tenant B grants permission for an actor/target in tenant A. Actor `active` and AI-actor owner are also not checked. |
| D2 | High | audit | `Object.freeze` is shallow: mutating the caller's `newValue` object after `record()` alters stored history. Empty `reason` accepted. No correlation/request id, source, or integration id. |
| D3 | High | payrollExport | Claim key has no tenant (`ledger:entryId`): cross-tenant false duplicates, and one tenant's `reverse()` can release another tenant's claim. `reverse()` mutates the claim in place and re-claim overwrites it — prior export history is lost. No actor/reason/vendor/period/attempt/response. |
| D4 | High | mileage | Dates compared as strings with no format validation: `"2026-1-5"` (Jan 5) is **priced at the July rate 0.76**. Overlapping rate rows are not detected (first match wins). Money is float. Accountable-plan day counts are module constants, not injectable rules. |
| D5 | Med | classification | `classification: "exempt"` with `exemptionCategory: "non_exempt"` passes. No explicit unresolved/pending state. `salaryLevelMet` is caller-asserted, not computed from salary facts vs. an effective-dated threshold. |
| D6 | High (compliance) | leave | NJ per-diem gate omits a statutory criterion — "works on an as-needed basis to supplement a health care employee, or to replace or substitute for a temporarily absent health care employee" (P.L.2018 c.10 §1). The gate can grant the exemption when the statute would not. Not a probe finding; a statutory-text comparison. **Fix requires changing Golden Test 5 fixtures** (see OPEN-QUESTIONS #11). |
| D7 | Med | leave | `accrueNjEarnedSickLeave(hoursWorked, priorAccrued)` caps a single number at 40, conflating the per-benefit-year accrual cap, the use cap, and the carry-forward cap (three separate 40-hour limits in the statute). Frontload payout-or-carry-forward rule not modeled. |
| D8 | High (payroll) | time | `minutes` is not reconciled with `startsAt`/`endsAt` (10h counted for a zero-length entry). Travel compensability comes from a user-chosen static kind rather than being derived from the day's sequence (first principal activity / continuous workday, office stops, required meeting point, outside normal hours, away from home community). Taxonomy lacks office↔client and meeting→client. Segment policy is not effective-dated or jurisdictional. |
| D9 | Low | leave | `deriveAvailableHours` sums all leave (paid, unpaid, any date); comment says per-day floor, code floors the total. |
| D10 | High (when DB lands) | schema | RLS `ENABLE`d without `FORCE` — table owners bypass RLS (PostgreSQL docs, verified). No policies. Single-column FKs (`actor_id → actor(id)`) allow cross-tenant references; should be composite `(tenant_id, id)`. |
| D11 | Low | tests | Golden Test 3 asserts `toBeCloseTo(28.424, 2)` against a cent-rounded amount (passes, but expects the unrounded value). Tests build `Date`s from zone-less strings (host-TZ dependent; no current result depends on it). **Not changing golden tests** — stronger tests will be added alongside. |
| D12 | Low | tooling/docs | No lint/format, coverage, or secret scanning; `package.json` `main: index.js` is stale; `PROJECT-STATE.md` "environment reality" section described the old sandbox. |

## 4. Research corrections (details in `RESEARCH-LOG.md`, 2026-09-26 entries)

- **IRS 2026 H2 mileage source** is IR-2026-29 per irs.gov, not "Announcement 2026-11 (IRB 2026-29)". Rates themselves verified (72.5¢ to 6/30, 76¢ from 7/1, by date driven). The medical/moving rate also changed (20.5¢ → 23.5¢); the bootstrap models business only.
- **Gusto**: Gusto's idempotency doc page describes version-based optimistic concurrency (409 on stale version) and **no idempotency keys**. Downgraded from VERIFIED. OCC prevents lost updates, not duplicate creates — client-side dedup is required for Gusto too.
- **NJ ESL per diem** definition has the additional as-needed criterion (D6); CHHA exclusion confirmed verbatim.
- **N.J.S.A. 34:6B-22**: "tracking device" = device "designed or intended to be used for the sole purpose of tracking…" excluding "devices used for the purpose of documenting employee expense reimbursement". Conservative always-notify default stands.
- **NJ EVV** (DMAHS): live since 2021-01-01 for PCA, MLTSS Home-Based Supportive Care, DDD Individual Supports, DDD In-Home Respite, DDD Community-Based Supports; claims require EVV data since 2021-07-01; state vendor HHAeXchange. Home health per federal mandate from 2023-01-01.
- Confirmed unchanged: EAP $684/wk ($35,568/yr), HCE $107,432 (DOL WHD 2026-05-14; FR 2026-05-15); HIPAA Security Rule NPRM still proposed, final action targeted July 2027 (Long-Term Actions).
